# PixelFoundry IDE v1.0.0 — Krita-style shell + a much richer pixel editor

**v1.0.0 is the first major release**: the whole UI was rebuilt around Krita's docker/workspace layout,
the standalone pixel board gained a batch of practical editing tools, tile packs are browsable down to
every folder level, bilingual switching no longer leaves residue — plus a thorough dead-code cleanup.

---

## 🖥️ Krita-style shell (all 5 modes)

- **Menu bar**: File / Edit / View / Workspace / Help — new pixel canvas, open/save project, undo/redo,
  copy/paste/merge selection, theme, UI scale (0.8×–1.5×), fullscreen, reset panel layout, about.
- **Contextual toolbar**: workspace chip on the left, actions that follow the active mode on the right
  (each page implements `toolbar_actions()`).
- **Docker panels**: unified header (icon + title + fold chevron); **collapsing frees space** — a folded
  docker keeps only its header and hands the freed height to the other expanded dockers in the same
  column (stacked fill), restoring its previous height when re-opened; a whole dock collapses into a
  22px vertical tab.
- **Everything is drag-resizable**: parameter docks, asset docks and the canvas are joined by draggable
  splitters; widths and collapsed states are remembered per mode.
- Dark/light themes rewritten: docker headers, top-accent tabs, themed canvas backdrop and checkerboard.
- Fixed the blank window that flashed when switching pages (toolbar widgets were parentless and shown as
  top-level windows for one frame).

## 🖌️ Standalone pixel board

**New tools**

- **Shapes**: line / rectangle / ellipse with live drag preview, commit on release, one undo per shape
  (right-click for stroke / fill).
- **Symmetry drawing**: horizontal / vertical / four-quadrant mirror with the axis drawn on canvas
  (right-click to pick the axis).
- **Wrap-around drawing**: strokes continue on the opposite edge — seamless tiles (grass, brick, floor)
  line up in one pass.
- **Canvas transforms**: flip H/V, rotate 90° either way, crop to selection, canvas resize (content
  anchored to any corner), integer nearest-neighbour content scaling — all undoable.
- **Export**: 1×/2×/4×/8× nearest-neighbour PNG export, or one-click copy to clipboard.
- **Palette interop**: import/export GIMP `.gpl` palettes (Aseprite / Krita / GIMP), locked on import so
  drawing snaps to those colors.
- Default tool shortcuts: B pencil / E eraser / I eyedropper / G fill / L line / U rectangle /
  O ellipse / M select.

**In-pack folder browsing**

- Import `.tilepack`, exported zips, exported folders — **and plain image folders without a manifest**.
- Every folder level inside a pack is browsable and can be placed on the canvas: `atlas/` (47-tile
  sheets), `tiles/<terrain>/` (each individual tile), `textures/`, `source/` (raw AI sheets),
  `pieces/`, `props/`.
- Category switcher extended to all / terrain / buildings / props / sheets / atlases / tiles / textures,
  with search and lazy thumbnails.

## 🌐 Bilingual UI

- Fixed "switch to English and back to Chinese leaves English strings behind" (build-time translations
  were frozen as source IDs).
- Completed every remaining Chinese string in the English UI: menus, API settings, error messages,
  workflow logs, provider presets, placeholders.
- Round-trip scans report zero residue in both directions.

## 🧹 Quality & cleanup

- Removed dead code and duplication: 61 unused imports/variables, 25+ dead functions and methods, an
  entirely unreferenced dialog module, 62 duplicate English keys and 55 dead keys (1028 → 977);
  extracted shared modules for 5 copies of the PIL→Qt conversion, 2 copies of the building/wall art
  helpers and 4 copies of the workflow logging helpers.
- Fixed rare wrong-tile rendering caused by the map tile cache keying on `id()` (now identity-checked).
- Tests **527 → 600**, all passing; ruff (F/E9) reports zero findings.

## 📦 Download & run (Windows x64)

1. Download `PixelFoundry-v1.0.0-win64.zip` and extract it anywhere (avoid non-ASCII/spaced paths).
2. Double-click **`PixelFoundry.exe`**.
3. Try it offline with the **mock API**: Settings → tick "Use mock API (no key)".

> Portable: no registry writes; config and keys live in `%APPDATA%\PixelFoundry` (API keys encrypted on
> disk with Fernet). The zip bundles the Python runtime and all dependencies — no Python needed.

### Run from source

```bash
git clone https://github.com/xf785/PixelFoundry-IDE.git
cd PixelFoundry-IDE
python -m venv .venv
.\.venv\Scripts\activate        # Windows
pip install -r requirements.txt
python main.py
python main.py --demo           # demo mode, no API key required
```

## ⚠️ Known limitations

- Image-to-video quality depends on the provider; motion can be subtle — raise the frame count or use
  the playback-speed multiplier.
- Non-pixel-art images skip Perfect Pixel and fall back to resize + quantize.
- Very large frame sequences are slow (no big-image performance work yet).
- Sprite sheets depend on how well the image API understands grid layouts; some providers are unstable.

# PixelFoundry IDE v1.0.0 — Krita 式界面 + 像素编辑器新工具

**v1.0.0 是第一个大版本**：界面按 Krita 的 docker / 工作区布局重做，独立像素画板补齐了一批实用编辑工具，
瓦片包支持逐级目录浏览，中英双语切换不再残留，并做了一轮彻底的代码清理。

## 🖥️ Krita 式界面（全 5 个模式）

- **菜单栏**：文件 / 编辑 / 视图 / 工作区 / 帮助 —— 新建像素画布、打开/保存项目、撤销/重做、
  复制/粘贴/合并选区、主题切换、界面比例（0.8×–1.5×）、全屏、重置面板布局、关于。
- **上下文工具条**：左侧是当前工作区标识，右侧动作随工作区切换（由各页面的 `toolbar_actions()` 提供）。
- **docker 停靠面板**：统一的标题条（图标 + 标题 + 折叠箭头）；**折叠即让位** —— 收起的面板只留标题条，
  腾出的高度自动分给同列其余展开面板（堆叠填充），再展开时按上次高度还原；整栏还能收起成 22px 竖标签。
- **所有分栏都能拖**：参数栏 / 资源栏 / 画布之间都是可拖拽分隔条，宽度与收起状态自动记忆。
- 深/浅色主题全部重写：docker 标题条、顶部高亮页签、主题化画布台面与棋盘格。
- 修复「切换页面时弹出一个空白窗口又立刻消失」（工具条控件原先没有父控件，会被当成顶层窗口显示一帧）。

## 🖌️ 独立像素画板

**新增工具**

- **形状**：直线 / 矩形 / 椭圆，拖动实时虚影预览、松开落笔，整个形状一次撤销（右键切描边/填充）。
- **对称绘制**：左右 / 上下 / 四象限镜像，画布显示橙色中轴，一笔出多笔（右键选轴）。
- **环绕绘制**：笔画越过边界从对侧续画 —— 画无缝瓦片（草地、砖墙、地砖）一次画对。
- **画布变换**：水平/垂直翻转、顺/逆时针旋转 90°、裁剪到选区、画布尺寸（内容四向锚点）、
  内容整数倍最近邻缩放（像素不糊），全部可撤销。
- **导出**：1×/2×/4×/8× 最近邻放大导出 PNG 或一键复制到剪贴板。
- **调色板互通**：导入 / 导出 GIMP `.gpl` 调色板（Aseprite / Krita / GIMP 通用），导入后自动锁定吸附。
- 工具快捷键默认值：B 铅笔 / E 橡皮 / I 取色 / G 填充 / L 直线 / U 矩形 / O 椭圆 / M 选择。

**瓦片包逐级目录浏览**

- 导入 `.tilepack`、导出 zip、导出文件夹，**以及没有 manifest 的普通图片文件夹**。
- 包内**每一级目录**都能浏览并送入画布：`atlas/`（47 图集）、`tiles/<地形>/`（逐张单瓦片）、
  `textures/`（纹理）、`source/`（文生图原始底图）、`pieces/`、`props/`。
- 分类切换器扩展为 全部 / 地形 / 建筑 / 素材 / 底图 / 图集 / 单瓦片 / 纹理，配搜索与懒加载缩略图。

## 📦 下载与运行（Windows x64）

1. 下载 `PixelFoundry-v1.0.0-win64.zip` 并解压到任意目录（建议路径不含中文/空格）。
2. 双击目录里的 **`PixelFoundry.exe`** 启动。
3. 首次启动可直接用**模拟 API 离线体验**：设置 → 勾选「使用模拟 API（无密钥）」。

> 绿色免安装：不写注册表，配置与密钥保存在 `%APPDATA%\PixelFoundry`（API Key 用 Fernet 加密落盘）。
> 压缩包内已包含 Python 运行时与全部依赖，无需安装 Python。

### 从源码运行

```bash
git clone https://github.com/xf785/PixelFoundry-IDE.git
cd PixelFoundry-IDE
python -m venv .venv
.\.venv\Scripts\activate        # Windows
pip install -r requirements.txt
python main.py
python main.py --demo           # 无需 API Key 的演示模式
```

## ⚠️ 已知限制

- 图转视频质量依赖服务商，动作幅度可能偏小，可用「播放倍速」或增加帧数改善。
- 非像素风图片会被像素化流程判定后跳过完美像素，改走缩放 + 量化。
- 超大分辨率帧序列处理较慢（未做大图性能优化）。
- 精灵图依赖生图 API 对网格图的理解，个别服务商效果不稳定。
