# 瓦片地图模式（第 5 模式）设计文档

> 状态：核心算法层已完成并有测试保障；工作流与 UI 集成待开发。
> 相关模块：`core/tilemap/`（prompts / tiles / seamless / autotile / map），
> 测试：`tests/test_tilemap_core.py`（14 项，含无缝不变量与 47 计数证明）。

## 1. 模式总览

1. **文生瓦片集**：文本描述纹理/风格 → 内置严格 3×3 九宫格提示词（中心=无缝
   纹理、四边=单侧直线边界的墙面瓦片、四角=圆角切角瓦片、纯白背景、统一
   调色板）→ 生图 API。
2. **自适应裁切**：`crop_base_3x3`——单格尺寸 = floor(min(w,h)/3) 取偶，
   整图居中取 3×cell 区域等分裁 9 张；`normalize_tileset` 归一化到目标规格
   （最近邻保持像素硬边）。
3. **逐瓦片重绘**（UI 待做）：复用 `core/editing/canvas.PixelCanvas`。
4. **无缝化算法**（`seamless.py`，确定性、无 AI）：
   - 纹理：顺序镜像平均（先水平后垂直，数学上保证 left==right 且
     top==bottom 逐像素相等），再重量化回原调色板；
   - 墙面：旋转到「边界朝上」，沿边界轴镜像平均（线带不动），四边线带
     统一为同一线色 → 长墙无限重复、四朝向风格一致；
   - 转角：由无缝中心纹理 + 统一线色按位掩码构图推导（构造性零接缝），
     AI 角瓦片仅可选低权重混合内部细节。
5. **47-tile / 双网格**（`autotile.py`，用户可选）：
   - 47 集：8 邻域位掩码（TL=1,T=2,TR=4,L=8,R=16,BL=32,B=64,BR=128）→
     几何构图：空侧画边界线；四角「两侧同空（外角）或两侧同满且对角空
     （内角）」时切半径 s/2 四分之一圆盘（弧线过边中点），弧线描边、弦
     不描边；地形一律取中心纹理。
   - 双网格：同一构图规则在 2 倍分辨率下以 4 类四分之一块（填充/上直切/
     左直切/转角盘）铺出，导出 2× 索引图。
6. **大网格预览**（UI 待做）：`TileMapModel` 铺设/擦除/矩形填充，按邻域
   位掩码自动衔接，`render()` 输出整图（47 或 dual 模式）。

## 2. 47-tile 数学依据

- 全 256 种掩码按视觉等价归并：k=4 全边满 16 种（四内角各由对角位决定）、
  k=3 缺一边 16、k=2 相邻 8、k=2 相对 2、k=1 仅一边 4、k=0 孤立 1，
  **总计 47**。实现为按组枚举 + 图像去重（`_group_masks`）。
- 孤立足（mask=0）与「四内角」（四边满、对角全空）图形重合（同为四角
  圆盘切），经典模板惯例保留两个槽位：实现输出 47 槽、46 张独立图像，
  `meta.mask_to_index` 覆盖全部 256 掩码。
- 无缝性不变量（有测试证明）：随机地图中任意相邻两格共享边上的不透明
  像素**逐像素一致**，唯一允许的差异位于共享边两端 r+2 像素内的转角区
  （内角缺口之「弦」落在相邻瓦片一侧，为 Godot 同款预期外观）。

## 3. 测试保障（tests/test_tilemap_core.py）

- 裁切自适应与规格归一；提示词强约束项。
- 纹理 wrap 逐像素相等（双轴）、确定性；墙面轴向 wrap + 线带统一；
  `process_base_set` 四边线色统一、转角与中心/墙面共享边一致。
- 构图几何：全邻=中心纹理；孤立四角切中心留；外角/内角/对角位语义。
- 47 集：计数、256 掩码全映射、46 唯一图 + 47 槽、全邻/孤立槽位校验、
  确定性。
- 地图：铺设/擦除/序列化、掩码值、随机图共享边不变量、双网格块类型。
